This is a template file for Montaigne TTS.
You can use it to easily try different text inputs.

Remember the markup options:

1. Pauses: Control the rhythm using [p=SECONDS] or [pause=SECONDS].
   - A short pause: Wait for it... [p=0.3] done.
   - A medium pause: Take a breath [pause=0.7]. Now continue.
   - A longer pause: That was unexpected. [p=1.5] Let's proceed.
   (Note: These are approximated using punctuation , . ...)

2. Emphasis: Add subtle emphasis using asterisks.
   - Use *single asterisks* for mild emphasis.
   - Use **double asterisks** for slightly stronger emphasis. This is **really** important.

3. Tone Tags: Mark sections for intended tones (currently logged but ignored by XTTS).
   - He spoke in a [tone=velvet]smooth voice[/tone].
   - The announcement came in a [tone=neutral]neutral tone[/tone].
   - Maybe it sounded [tone=gold]expensive[/tone]?
   - Other supported tags are [tone=silver]silver[/tone] and [tone=bronze]bronze[/tone].

Combine them!
This requires *very careful* consideration. [p=0.8] **Do not** proceed otherwise. The result, hopefully [tone=gold]perfect[/tone], depends on it.

Now, replace this text with your desired script for synthesis!
